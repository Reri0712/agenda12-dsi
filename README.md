# Atividade - Meus Sites Favoritos (Agenda 12)

O objetivo desta atividade é o desenvolvimento de uma página web estruturada em HTML5 para organizar e exibir links de sites favoritos, aplicando os conceitos de:
* Estruturação básica de documentos HTML (`DOCTYPE`, `html`, `head`, `body`).
* Uso de títulos (`<h1>`, `<h2>`) e quebras de linhas estruturais.
* Inclusão de imagens e legendas com as tags `<figure>`, `<img>` e `<figcaption>`.
* Criação de hiperlinks externos utilizando a tag `<a>` com o atributo `target="_blank"`.

## 🌐 Sites Selecionados
1. **GitHub**
2. **YouTube**
3. **Google**
4. **Amazon**
5. **Canva**

## 🛠️ Tecnologias Utilizadas
* HTML5
* Visual Studio Code (VS Code)
